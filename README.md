# Sales-Dashboard-ETL-Pipeline: Excel → Python → MySQL → Power BI
Project Overview

This project demonstrates a complete End-to-End ETL (Extract, Transform, Load) pipeline built using Python, MySQL, and Power BI. The goal was to transform raw and unstructured Excel data into meaningful business insights through data cleaning, database management, and interactive visualizations.

Problem Statement

Organizations often work with raw Excel files that contain missing values, duplicate records, inconsistent formats, and inaccurate data. Such datasets are difficult to analyze directly and can lead to poor decision-making.

This project addresses these challenges by creating an automated workflow that cleans and transforms raw data before storing it in a centralized database and visualizing key insights through dashboards.

ETL Workflow
1. Extract
Imported raw Excel data into Python using Pandas.
Examined dataset structure, data types, and quality issues.
2. Transform

Performed extensive data cleaning and preprocessing, including:

Handling missing values
Removing duplicate records
Correcting inconsistent formatting
Standardizing column names
Converting data types
Filtering invalid records
Creating derived columns for analysis
3. Load
Connected Python to MySQL.
Loaded the cleaned dataset into a MySQL database.
Stored data in structured tables for efficient querying and reporting.
4. Visualization
Connected Power BI directly to MySQL.
Built interactive dashboards and reports.
Created KPIs, charts, and business metrics for decision-making.
